# GUI 阶段规划（合规版）

> 目标：让不熟悉命令行的玩家也能安全地使用 fps-tune。
>
> **当前状态**：功能版 `delta-gui.ps1` 已实现（检测 / 优化授权 / A/B 实验 /
> 朋友测试 / 备份日志）。视觉设计后续交给 V4 flash version，提示词见
> [GUI_DESIGN_PROMPT.md](GUI_DESIGN_PROMPT.md)。
> 原则：GUI 只做“调用脚本 + 展示结果 + 确认授权”，所有系统改动仍由
> `fps-tune.ps1` / `tuning-experiment.ps1` 完成，GUI 不绕过备份与还原机制。

## 明确不做

- 显卡型号伪装（红线，已拒绝）
- 外置准星 / 悬浮窗 / Overlay（独立工具，不并入本项目）
- 游戏目录文件修改、进程注入、反作弊交互
- 代替用户下载或安装任何软件（PresentMon / VC++ / 驱动等）
- 自动勾选免责声明或代替用户确认

## 页面/模块

### 1. 首页：检测与概览

- 调用 `fps-tune.ps1 -Detect -Json`
- 展示：
  - CPU / 内存 / 显卡 / 系统版本 / 是否笔记本 / 是否管理员
  - 游戏路径（找不到时允许用户手动选择主程序）
  - 22 项优化当前状态（已达标 / 未应用）
  - 3 项只读体检结果（VC++ / 内存频率 / PCIe）
  - 显卡驱动内手动设置清单（按厂商生成）
- 提供“重新检测”按钮。

### 2. 优化页：选择与授权

- 三套预设卡片：`full` / `balanced` / `safe-only`
- 逐项列表：每项显示 id、作用、副作用、是否需要管理员、是否需要重启
- 用户勾选后点击“下一步”，弹出确认页：
  - 汇总将执行的项
  - 高亮需要重启的项
  - 高亮有副作用的项（wsearch-off / hibernate-off 等）
- 必须用户手动勾选“我已阅读并同意上述说明”后，才允许调用：
  - `fps-tune.ps1 -Apply -Items ... -Force -Json`
- 执行后展示：成功 / 失败 / 跳过、备份文件路径、需重启项列表。
- 提供“一键还原”入口。

### 3. A/B 实验页

- 检测 PresentMon 是否可用（`Get-Command PresentMon` 或已知路径）
- 未安装时只展示官方安装命令，不代为安装
- 基线按钮：`tuning-experiment.ps1 -Baseline -Json`
  - 显示平均 FPS / 1% low / P99 / 卡顿 / CV
  - CV > 0.05 时禁止继续，提示用户重新采样
- 候选组按钮：group-1 / group-2 / group-3
  - 显示每组 keep / revert 结果与原因
- 报告按钮：显示汇总表，并打开 CSV 路径
- 采样前提示：固定场景、画质、路线，保持前台，不要切窗口

### 4. 朋友测试页

- 集成 `friend-test.ps1` 的表单：
  - 自动读取 CPU / GPU / 内存 / 系统
  - 填写场景/画质、前后平均 FPS、前后 1% low、备注
- 生成 Markdown + CSV，支持“复制表格到剪贴板”和“打开所在文件夹”

### 5. 显示与 ICC 滤镜（阶段 2，可选）

- 列出显示器设备
- 允许用户选择 `.icc` / `.icm` 文件并应用到指定显示器
- 提供几个合规预设：
  - 标准（不改变）
  - 提亮 / 高对比 / 鲜艳（基于 ICC 或驱动级色彩设置）
- 不做游戏内画面滤镜、不注入、不 Overlay

### 6. 备份与审计页

- 列出 `%LocalAppData%\FpsTune\backup\` 下备份
- 展示每个备份可还原的项
- 支持按项或全部还原，展示 `.restored` 消费记录

### 7. 日志与导出页

- 展示最近一次命令的 JSON 原文
- 一键导出检测报告 / A/B 报告 / 朋友测试记录
- 一键打开状态目录

## 技术方案建议

- **阶段 1**：PowerShell 5.1 + WinForms 单文件 `delta-gui.ps1`
  - 零依赖，Windows 10/11 自带
  - 仅封装现有 CLI，不引入新引擎逻辑
  - 文件保存为 UTF-8 BOM
- **阶段 2（可选）**：如果用户量上来，再考虑 C# / WPF 重写或加安装包
  - 仍然只做外壳，不改变核心脚本行为

## 里程碑

1. M1：检测页 + 优化授权页 + 还原入口
2. M2：A/B 实验页 + 朋友测试页
3. M3：备份审计页 + 日志导出页
4. M4（可选）：ICC 滤镜页
