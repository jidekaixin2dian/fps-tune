## 排期口径

- **P3 系列**是现行唯一的排期清单（下表）。P0（挡发版的正确性问题）/ P1（发版范围承诺）/
  P2（增强）三层的历史任务已全部收口或转入下节「暂停 / 暂缓项」。
- 没有用户点名的新需求时，默认方向 = 深度自查 或 优化项扩展调研（P2-6 / P3-10 模式：
  先调研、红线预审、用户拍板再落地）。
- 产品红线（`docs/ROADMAP.md` §产品定位）不可让步：安全闭环 / 零侵入 / 数据说话 / 全 FPS 通用 / 可信透明。

## 明确不做 / 不要误做的

- 不向 `legacy/1.x` 修 bug、发版、升级 .NET。
- 不改 CLI `-Json` 输出格式（有测试逐字节依赖）。
- 不读游戏内存、不注入、不与反作弊交互、不关引导虚拟化（红线「零侵入」）。
- 不把 README 模拟/历史实验数字当真实收益宣传。
- SettingID 未以 `nvapi.h` 核实前不写死进 catalog。
- 优化项扩展的"不做"结论（图像锐化 / 三重缓冲 / Spectre 缓解 / VBS / HPET 等）
  见 `PLAN-P2-6-hot-options.md` 与 `PLAN-P3-10-catalog-expansion.md`，**不要重查重提**。
