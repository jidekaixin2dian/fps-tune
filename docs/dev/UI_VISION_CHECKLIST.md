# fps-tune「FPS 帧律」UI 视觉优化设计清单

> 用途：交给 vision 模型执行 WPF UI 现代化改版。
> 硬约束：只允许改 UI/视觉/布局，不得破坏现有功能与核心引擎合规边界。

---

## 0. 版本与总原则

- 当前版本仍为 `1.0.0`，UI 改版不得改版本号。
- 设计方向：Windows 11 风格 / 现代化工具类桌面软件。
- 观感目标：克制、清晰、专业、低视觉噪音；不要电竞风、不要霓虹泛滥、不要花哨动画堆砌。
- 一切页面必须同时适配 **深色 / 亮色 / 跟随系统** 三种模式。
- 所有控件状态必须完整：默认、Hover、Pressed、Disabled、Focus。
- 所有可点击元素必须有明显 Hover 反馈和键盘焦点可见样式。
- 所有文本在深色/亮色下必须满足可读性对比度（正文不低于 4.5:1，大字不低于 3:1）。
- 不得出现大面积空白；每一页内容应填满可用区域或给出明确的空状态说明。
- 滚动条必须保持当前“细滚动条、可拖动、线性”的特性，禁止回到默认笨重滚动条。
- 设置页禁止出现“开发者联系方式编辑”入口。
- 微信联系方式：只显示“请点击查看二维码”，点击弹二维码，不做公开主页链接。
- QQ：`https://qm.qq.com/q/jwbacnxrmU`
- 抖音：`https://v.douyin.com/sf-DA6eLcjQ/`
- 联系方式仅接受合作/反馈；不得出现“打赏开发者”入口（公开发布后再议）。
- 不得修改：游戏文件、进程注入、反作弊交互、引导虚拟化、显卡伪装等合规边界。

## 1. 全局视觉规范

### 1.1 字体与排版
- 全局字体：`Microsoft YaHei UI`。
- 页面标题：20px / Bold。
- 卡片标题：12px / SemiBold / 次要色。
- 正文：13px / 常规色。
- 辅助说明：11–12px / 弱化色。
- 数字指标（FPS、P99 等）：28–30px / Bold / 等宽数字优先（`Cascadia Mono` 或 `Consolas`）。
- ID/路径/JSON：`Cascadia Mono, Consolas`，12px。
- 行高：正文 1.5–1.7，多行文本必须 `TextWrapping`。

### 1.2 间距与栅格
- 页面外边距：24px。
- 卡片内边距：16–20px。
- 卡片圆角：12px。
- 控件圆角：8–12px。
- 按钮最小高度：36px。
- 模块间距：14–20px，同类卡片统一。
- 左右分栏比例保持可读：左列表 44–46%，右内容 54–56%。

### 1.3 颜色（深色 / 亮色）
- 深色：
  - 背景 `#09090B`
  - 侧栏 `#0C0C0E`
  - 卡片 `#111113`
  - 悬浮卡片 `#131316` / `#18181B`
  - 边框 `#26262A` / Hover `#3F3F46`
  - 主文本 `#F4F4F5`，次要 `#A1A1AA`，弱化 `#71717A`
  - 主色绿 `#10B981`，强调青 `#22D3EE`
  - 警告 `#FBBF24`，危险 `#F87171`，成功 `#34D399`
- 亮色：
  - 背景 `#F4F4F5`，侧栏 `#FAFAFA`，卡片 `#FFFFFF`
  - 主文本 `#18181B`，次要 `#52525B`，弱化 `#71717A`
  - 主色 `#059669`，强调 `#0891B2`
  - 警告 `#D97706`，危险 `#DC2626`，成功 `#059669`
- 状态色只用于表达状态，不用于大面积铺色。

### 1.4 图标
- 继续使用 `Segoe MDL2 Assets`。
- 图标大小统一：导航 20px，功能卡片 20px，状态提示 16–20px。
- 图标必须与功能语义匹配；禁止图标和文字混搭失衡。

### 1.5 动效
- 动效只做：页面切换淡入 + 轻微滑动、按钮 Hover 缩放、卡片 Hover 抬升/描边。
- 时长 120–220ms，缓动 `QuadraticEase`。
- 禁止：弹跳、旋转、闪光、连续无限动画。
- 所有动画不得阻塞操作，不得导致 UI 线程卡顿。

### 1.6 焦点与可访问性
- Tab 键可以按顺序遍历主要按钮/列表。
- 焦点态：可见描边或外发光，颜色使用强调青。
- 所有按钮/复选框/列表项必须有 `ToolTip` 或可读的文本标签。

## 2. 主窗口与侧边导航

### 2.1 主窗口
- 窗口默认尺寸建议：1200×760，最小 1080×680。
- 背景使用统一 `AppBackgroundBrush`。
- 如果用户拖拽改变窗口大小，各页必须能自适应；不要出现内容被截断或大片空白。
- 主题切换时：整个窗口先淡出再淡入，当前已有动画可保留并优化节奏。

### 2.2 侧边导航
- 导航项：首页、检测、优化、A/B 实验、朋友测试、备份/日志、设置。
- 激活态：左侧 3px 强调色竖条 + 轻微背景 + 描边。
- Hover：只改变背景与描边，不跳动。
- 导航栏宽度固定，建议 220–240px，不要把文字压成两行。
- 底部可加一行小字：`v1.0.0`。

## 3. 首页

### 3.1 顶部联系区
- 微信：显示“请点击查看二维码”，点击弹出二维码窗口。
- QQ：显示 QQ 号/链接，点击打开 `https://qm.qq.com/q/jwbacnxrmU`。
- 抖音：显示抖音号/链接，点击打开 `https://v.douyin.com/sf-DA6eLcjQ/`。
- 仅显示“合作/反馈”语义，不要出现“打赏”。
- 联系项不要挤在右上角；如果空间不足，可做成右侧小型按钮组。

### 3.2 Hero 区
- 左侧：产品图标（120×120 圆角方形）。
- 右侧：产品名、一句话简介、合规说明、版本号、硬件摘要。
- 硬件摘要要完整展示 CPU / GPU / 内存，超出可折行，但不要截断。
- “检测并优化”按钮仅首次启动显示，视觉上做强调主按钮。

### 3.3 功能模块卡片
- 六张卡片：检测、优化、A/B 实验、朋友测试、备份/日志、设置。
- 每张卡片：图标、标题、一句话说明。
- 卡片高度统一，说明文本两行以内；不要出现明显高低不一。

## 4. 检测页

### 4.1 硬件信息卡片
- 字段：CPU、GPU、内存、系统版本、笔记本、管理员。
- GPU 可能较长（独显 + 核显），必须 `Wrap` 或 `ToolTip` 显示完整。
- 标签列宽固定，右侧值可折行。
- 管理员“是/否”可用小徽章，不用大段文字。

### 4.2 游戏路径 / 只读体检卡片
- 游戏路径长，必须可折行 + 可复制。
- 体检项（VC++、内存频率、PCIe）用状态徽章 + 一行说明：
  - 正常：绿点 + 简要说明
  - 注意：黄点 + 说明
  - 未知：灰点 + “未识别，建议…查看”
- 状态徽章颜色只做点缀，不铺满。

### 4.3 优化项概览列表
- 每项：ID、名称、说明、副作用（有则显示，无则隐藏）、当前状态徽章。
- 副作用行用警告色文字，但不要比名称更抢眼。
- 当前状态：已达标/未应用，做成轻量徽章，不要用大色块。
- 列表应能滚动到底；底部不要被截断。

### 4.4 检测详情
- 使用等宽字体文本框。
- 顶部可加“复制全部”小按钮，方便用户反馈。
- 空状态：未检测时显示引导文案“点击右上角运行检测”。

## 5. 优化页

### 5.1 顶部操作区
- 应用 = 主按钮；还原全部 = 危险按钮（红色，但不要过亮）。
- 预设按钮组：full / balanced / safe-only / 自定义勾选，选择态要清晰。

### 5.2 优化项列表
- 每项：复选框、ID、名称、说明、副作用（有则显示，无则隐藏）、管理员/需重启标签。
- 管理员/需重启做成小标签（描边或浅色底），不要用醒目大色块。
- 勾选后当前行可有轻微背景变化，方便识别。

### 5.3 执行结果
- 成功/失败/跳过逐项列出，带 `[成功]` `[失败]` `[跳过]` 状态标签。
- 汇总信息单独一行，视觉上突出。
- 备份路径可复制。
- 需重启项可高亮提示，但不要弹窗打断。

---

## 6. A/B 实验页

### 6.1 操作步骤
- 1 基线 / 2 group-1 / 3 group-2 / 4 group-3 / 5 报告，五个步骤做成步骤条或按钮组。
- 当前步骤运行中显示 Loading/禁用态，避免重复点击。

### 6.2 状态横幅
- 运行中：强调色描边 + 动态文本。
- 完成：成功色描边。
- 失败：危险色描边。

### 6.3 指标卡片
- 平均 FPS、1% low、P99、卡顿、CV、结论。
- 数字 30px，底部标签 12px。
- 六张卡片等宽等高，数字不要溢出。
- 结论为空时显示 `--`，不要空白。

### 6.4 原始输出
- 等宽字体，可复制，可滚动。

---

## 7. 朋友测试页

### 7.1 表单
- 左侧表单：昵称、场景/画质/设置、优化前平均 FPS、优化前 1% low、优化后平均 FPS、优化后 1% low、备注。
- 输入框高度统一 36px，备注可多行。
- 必填项应有轻提示（如星号或占位符说明）。
- 布局两列时字段宽度保持一致。

### 7.2 Markdown 预览
- 右侧预览使用等宽字体。
- 预览为空时显示“填写表单后自动生成预览”，不要空白。

---

## 8. 备份 / 日志页

### 8.1 操作按钮
- 列出可还原项、还原全部、打开备份目录、打开 GUI 临时目录、导出日志。
- 还原全部用危险按钮，其余用次级按钮。
- 按钮区不要拥挤，可分两行或加图标。

### 8.2 目录信息卡
- 备份目录、GUI 临时目录、当前状态三张卡片。
- 路径超长时折行 + 可复制。

### 8.3 日志输出
- 等宽字体，可复制，可滚动到底。
- 空状态显示“点击上方按钮查看输出”。

## 9. 设置页

### 9.1 常规
- 默认启动主题：深色/亮色/跟随系统。
- 保存按钮用主按钮。

### 9.2 关于 / 合规
- 版本号、简介、合规说明、联系方式说明。
- 合规说明保持完整，不能因样式被截断。

### 9.3 更新与管理员
- 检查更新按钮 + 更新状态文本。
- 管理员状态：是/否徽章。
- 非管理员时显示“以管理员身份重启”按钮。
- 禁止出现开发者社交账号编辑。

## 10. 弹窗规范

### 10.1 微信二维码弹窗
- 居中、圆角卡片、阴影。
- 二维码图片清晰，固定合适尺寸。
- 显示“微信号：…”和“仅接受合作/反馈”。
- “复制微信号”按钮用主按钮。

### 10.2 自定义对话框
- 已存在 `AppDialogWindow`，继续沿用并美化。
- 图标 42×42 圆形底 + MDL2 图标。
- 标题 16px Bold，正文 13px，行高 22px。
- 确认/取消按钮高度 36px，宽 96px 起。
- 危险确认按钮使用红色实底，非危险确认用主色。
- 支持 Esc 关闭，遮罩可点击关闭（可选，但不能误触）。

## 12. 禁止事项

- 禁止改版本号。
- 禁止改动任何 C# 核心引擎逻辑（NativeOptimizationEngine / BackupService / DetectionService / HardwareInfoService / GamePathService / OptimizationEngine）。
- 禁止在设置页加开发者社交账号编辑。
- 禁止加“打赏开发者”入口。
- 禁止使用系统默认 MessageBox 替代自定义弹窗。
- 禁止破坏合规边界（不碰游戏文件、不注入、不绕过反作弊、不关虚拟化、不伪装显卡）。
