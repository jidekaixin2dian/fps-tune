# 优化页控制台改版

页面沿用控制台的深浅色纯色背景、青色操作色和细分隔线。顶部选择预设，中间分类与搜索，左侧浏览优化项，右侧查看完整详情与执行记录，底部固定显示待应用数量、权限要求、同意开关和执行操作。配置方案折叠收纳，原有保存、载入、删除、导入和导出保留。

列表区分系统状态与待应用开关。名称保留换行，说明和副作用显示摘要，悬停或点击项目可读完整内容。手动调整会进入自定义模式，避免执行时忽略手动选择。选择变化会重置同意状态；搜索和分类不会清除其他分类的选择。无搜索结果有明确提示。

验证：185 项现有测试通过，Release 构建零警告、零错误。实际窗口验证了列表加载、选择数量更新与项目详情。独立 WPF 探针验证分组刷新、重复加载、检测快照更新、自定义选择保留、手动取消后的实际执行 ID、同意状态重置、搜索空状态，并渲染深浅色 1080 和 1440 宽度的真实页面。未实际应用系统优化或还原备份。

复现命令（仓库根目录，Windows .NET 8）：

```powershell
dotnet run --project tools/OptimizeViewProbe/OptimizeViewProbe.csproj -c Release
```

探针使用内存检测快照，渲染图保存在 `review-output/optimize-{dark|light}-{1080|1440}.png`，不修改用户配置或系统优化项。
