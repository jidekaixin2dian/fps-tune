# 三角洲玩家流程：第一轮迭代

本轮入口位于紧凑控制台概览，经典模式保留原有布局。玩家可从同一区域定位三角洲、审阅基础建议、进入性能会话或备份还原。

- 游戏定位后台搜索已有支持的安装目录；仅一个主程序候选时使用该目标，否则让用户选择。拒绝启动器，保存成功后更新检测。选择目标与检测快照不一致时必须重新检测。
- 基础建议只带入尚未达标的游戏模式、后台录制和游戏显卡偏好。沿用优化页的说明、副作用、同意、权限与备份流程，不直接应用系统更改。服务、启动配置、电源及输入手感改动不纳入此入口。
- 记录一局打开性能会话，空名称时预填三角洲对照记录，保留用户已经填写的名称和正在运行的会话。提示使用相同地图、画质、帧率上限及相近时长进行对照。需要用户主动开始；测量的是负载，不是游戏帧率。
- 清空手动游戏路径时同步清空内存目标；检测没有目标时也清空旧路径，避免沿用过时目标。

验证：192 项单元测试通过。真实 WPF 控件探针覆盖未定位时禁用建议、旧目标快照不能使用、新目标检测后可使用、会话名称保留且不会自动采样；检查深浅主题的 1080/1440px 页面渲染。Release 构建成功；NuGet 漏洞数据查询出现网络不可达警告，未完成依赖安全审计。没有实际应用优化、还原、自动选择用户游戏路径或进行三角洲对局效果测试。

本轮是 v1.6.2 之后的本地源码迭代，尚未发布新的安装包。后续效果改进应以实际帧时间采集、相同场景对照和回归验证为基础，不以“已达标项目数”代替性能收益。
