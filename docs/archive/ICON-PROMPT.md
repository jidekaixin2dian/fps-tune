# FPS 帧律图标生成提示词

生成一张用于 Windows 桌面软件「FPS 帧律」的应用图标候选，不要生成界面或展示样机。

画面规格：1024 × 1024，正面平视、居中对称的方形构图。近黑色圆角方块底板，圆角之外透明。保留足够安全边距，图形主体约占宽度的 72%。

主体：一个清晰、简洁的速度表符号。一条粗壮的电光青色开放圆弧，一根指向右上方的浅青白实心指针，只保留三个较宽的刻度。缩到 24 × 24 时，圆弧和指针仍然可以分辨。

风格：现代精密仪器，克制、稳重，有轻微缎面质感和极浅倒角，整体接近平面。强调大轮廓和黑青对比，不靠密集细节或强发光制造科技感。建议底色 #07090B，主色 #22D3EE，指针 #D7FAFF。

不要出现：文字、字母、数字、水印、紫色、彩虹渐变、复杂刻度、粒子、背景场景、夸张光晕、强烈透视、厚重立体效果、多图拼接、手机或电脑样机。

只输出一个完整图标。此图用于确认方向，确认后再制作 16 / 24 / 32 / 48 / 256 像素的图标文件，不直接用模糊缩放替代小尺寸检查。
