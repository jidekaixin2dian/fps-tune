# 中文控制台与实时图表修复

## 变化

- 默认使用紧凑中文控制台：四项实时指标、中文项目名称、细分隔线、方案选择和搜索。
- 标题栏切换经典 / 控制台模式并持久保存；切换时保留当前页。经典概览保留原有功能入口。
- 检测页在控制台模式使用数字和细进度条，经典模式保留折线图。不可用指标显示缺失状态，不填入伪造数据。
- 图表原先接收 120 点却按 60 点计算偏移，造成负横坐标；现在截取最近 60 点、约束百分比和绘图边界。尺寸变化触发重绘，缺失采样保持断点。
- 窗口改用非分层窗口的 WindowChrome / DWM 路径，恢复系统窗口过渡。最小化到托盘延后 250 ms，避免立即隐藏打断动画；尊重 Windows 自身动效设置。
- 采样计数器查询移到工作线程，最多一项正在执行的采样；回调在 UI 线程发布。停止和释放后丢弃过期结果。
- 性能历史加载移到后台；优化项只在检测快照更新时重建，页面切换保留选择。检测结果完整构建后替换快照，避免缓存看到半份数据。
- 控制台开关只选择项目，审阅按钮进入现有优化流程并重置同意状态；管理员要求、副作用提示和执行前备份仍由原流程处理。
